# Doqtra Product Vision

**Last Updated:** December 13, 2025

---

## The Core Insight

**Learning is like Minecraft, not like Netflix.**

Netflix shows you content in a predetermined sequence. Minecraft generates a unique world for each player based on how they explore and interact.

Traditional learning platforms are Netflix: everyone gets the same course. Doqtra is Minecraft: every learner gets a procedurally generated curriculum tailored to their goals, style, and progress.

---

## The Problem

### What's Broken in Current Learning Platforms

**Coursera, Udemy, LinkedIn Learning:**
- One-size-fits-all courses (same videos for everyone)
- No adaptation (beginner and expert watch identical content)
- Black box progression (can't see what's coming next)
- No agency (can't skip or add topics mid-course)

**Adaptive Learning Platforms (Duolingo, Khan Academy):**
- Adapt *difficulty* but not *content* (same lessons, easier/harder)
- Pre-generated content library (finite, static)
- Limited transparency (don't show full roadmap upfront)
- Narrow scope (single subject focus)

**Corporate LMS Platforms (Workday, SAP):**
- Mandatory training (not learner-driven)
- Compliance focus (checkbox mentality)
- Poor engagement (20% completion rates)
- Expensive content creation (weeks per course)

## The Doqtra Difference

### Procedural Generation (Like Minecraft)

**Traditional platforms:**
```
Content Team → Creates 50 lessons → Stores in database → Serves to all users
[Weeks of work] [Static forever] [Same for everyone]
```

**Doqtra:**
```
User profile → AI generates curriculum → Unique lessons → Adapt as user learns
[Seconds] [Dynamic] [Personalized]
```

### Full Transparency (Unlike Black Box AI)

**User sees everything before starting:**
- Complete roadmap (phases, modules, lessons)
- Estimated duration and time commitment
- All topics and skills covered
- Can expand any section for detail
- Can modify before and during learning

**Why this matters:**
- Builds trust (no surprise requirements)
- Empowers learner (agency over path)
- Sets expectations (realistic timelines)
- Enables planning (fits life schedule)

### Continuous Adaptation (Not Just Difficulty)

**After each lesson:**
- Rate confidence (1-5 scale)
- System analyzes performance
- Curriculum adjusts in real-time

**Example adaptations:**
```
Struggled with Lesson 5 → Add review lesson (Lesson 5.5)
Mastered Module 2 quickly → Skip Module 3 basics, jump to advanced
Showed interest in side topic → Generate optional deep-dive module
```

### Universal Platform (Any Topic)

**Phase 1 topics:**
- Excel (pivot tables, dashboards, Power Query)
- Python (scripting, data analysis, automation)
- Notion (workspace setup, databases, automation)
- Figma (design systems, prototyping, collaboration)
- Slack (workflows, integrations, best practices)

**Phase 2+ topics:**
- Music production (Logic, Ableton, mixing)
- Video editing (Premiere, DaVinci, Final Cut)
- Photography (Lightroom, composition, editing)
- Writing (copywriting, technical writing, blogging)
- Marketing (SEO, content strategy, analytics)

**No limit.** If a topic has learnable skills, Doqtra can teach it.

## Risks & Mitigation

### Risk 1: AI generates inaccurate lessons
**Mitigation:**
- Expert review for high-traffic lessons
- Community flagging system
- Fact-checking against trusted sources
- Continuous model updates

### Risk 2: Users don't trust AI-generated content
**Mitigation:**
- Transparent sourcing (show references)
- Human expert endorsements
- Curriculum preview (see before committing)
- Quality ratings (only show 4+ star lessons)

### Risk 3: Competitors copy approach
**Mitigation:**
- Speed (launch MVP in 6 months)
- Quality (best lesson generation, not just fastest)
- Network effects (content library improves with users)
- Brand (become known as "the personalized learning platform")

### Risk 4: Lesson generation costs too high
**Mitigation:**
- Content library (80% lessons served from cache)
- Tiered generation (basic lessons cheaper than advanced)
- Sponsor model (companies pay for employee curricula)
- Open-source contributors (community-generated lessons)
