## What Exists (Competitors)

### Category 1: Adaptive Learning Platforms

**Duolingo, Khan Academy, Coursera**
- ✅ Adapt difficulty based on performance
- ❌ Don't generate new content (adapt existing lessons)
- ❌ No curriculum preview (black box progression)
- ❌ Can't skip or add topics mid-journey

**Doqtra Advantage:** Procedural generation vs. adaptive difficulty

---

- ❌ Pre-generated content library (not just-in-time)
- ❌ Designed for corporate training (not consumer)
- ❌ No transparent roadmap preview

**Doqtra Advantage:** JIT generation + consumer focus + transparency

---

### Category 3: AI Education Tools

**ChatGPT, Claude, Perplexity**

- ✅ Personalized responses
- ❌ No structured curriculum
- ❌ No progress tracking
- ❌ No pedagogical framework (just Q&A)

**Doqtra Advantage:** Structured curriculum + progress tracking + pedagogy

---

### Category 4: Microschools (AI-Powered)

**Alpha School**
- ✅ AI-driven personalized instruction (K-12)
- ✅ Adaptive content based on mastery
- ❌ Physical school (not scalable software)

**Doqtra Advantage:** Software platform + adult learners + affordable

## What Doesn't Exist (Doqtra's Blue Ocean)

### No Competitor Has These Features:

1. **Procedural Curriculum Generation**
   - Minecraft-style: unique curriculum per user
   - Generated based on: goals + skill level + learning style + time available
   - Adapts mid-journey based on performance

2. **Full Roadmap Transparency**
   - See all phases, modules, lessons upfront
   - Expandable detail levels
   - Can modify before starting

3. **Learner Agency**
   - Skip modules ("I already know this")
   - Add modules ("Include advanced topics")
   - Regenerate curriculum anytime
   - System suggests, user decides

4. **Universal Platform**
   - Excel + Python + Notion + Figma + ... (any topic)
   - Same platform, different subjects
   - Content library grows across topics

5. **Content Library with Network Effects**
   - First user pays generation cost
   - Subsequent users get cached lessons (free)
   - Quality improves over time (ratings, refinements)
